# موتور ساخت محتوای داروخانه دکتر حصیبی

عکس محصول + متن در تلگرام → n8n متن جعبه را با Gemini می‌خواند و ادعاهای خارج از جعبه را حذف می‌کند → این مخزن با GitHub Actions می‌سازد:

- پست ۱۰۸۰×۱۳۵۰
- ۲ استوری ۱۰۸۰×۱۹۲۰
- ریلز ۱۸ ثانیه‌ای ۱۰۸۰×۱۹۲۰ با ۵ صحنه (پوستر، شیشه‌ای، نئون، پوستر بولد، اوترو استودیویی)، موزیک ساخته‌شده با کد و افکت (بدون گوینده)

و همه را به همان چت تلگرام برمی‌گرداند.

## راه‌اندازی (یک‌بار)
1. Settings → Secrets → Actions → `TELEGRAM_BOT_TOKEN` = توکن ربات جدید
2. تست: Actions → render-content → Run workflow (نمونهٔ مگنی‌فورت، خروجی در Artifacts)

## تنوع (هر ویدیو سبک خودش)

هر ریلز از روی `seed` یک «نقشه» می‌گیرد (`src/plan.ts`):
- **هوک (۱ از ۴):** تایپوگرافی کوبنده، زوم‌تایپ، دراپ محصول، گلیچ
- **صحنه‌های میانی (۳ یا ۴ از ۹):** شیشه‌ای سه‌بعدی، نئون، پوستر، اعلان گوشی، زیرنویس کلمه‌به‌کلمه، مدار، شبکهٔ ۲×۲، چک‌لیست، شمارنده — همیشه یکی برای ادعای روی جعبه، یکی برای ترکیبات و یکی برای تصویر محصول
- **پایان (۱ از ۳):** استودیویی، مینیمال با موج، کارت ویزیت چرخان
- **ترنزیشن‌ها:** پانچ، ویپ، زوم، گلیچ، دایره، اسلاید
- **پالت (۶)، بافت (گرین/نور/وینیت/هیچ)، تپش روی ضرب موزیک**
- افکت‌های صوتی دقیقاً روی همان فریم‌های حرکت (`out/plan.json`)

پیش‌نمایش سریع چند seed: `node scripts/preview.mjs job.sample.json out/preview 1 2 3`

### جزئیات قدیمی
`seed` در job، پالت، ترتیب صحنه‌های میانی، رنگ و شکل QR، ریتم و آکورد موزیک و افکت‌ها را عوض می‌کند.

## قوانین محتوا که در خود قالب قفل شده
- متن روی تصویر فقط از فیلدهای تأییدشده ساخته می‌شود (نام، ادعای روی جعبه، ترکیبات روی جعبه).
- «کوهپایه» همیشه سرهم نوشته می‌شود. «سلام کوهپایه» روی ویدیوها نمی‌آید.
- پاورقی ثابت: «ادعا فقط طبق نوشتهٔ روی جعبه • سؤال دارویی؟ با دکتر حصیبی مشورت کنید».
