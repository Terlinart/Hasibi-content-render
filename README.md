# موتور ساخت محتوای داروخانه دکتر حصیبی

عکس محصول + متن در تلگرام → n8n متن جعبه را با Gemini می‌خواند و ادعاهای خارج از جعبه را حذف می‌کند → این مخزن با GitHub Actions می‌سازد:

- پست ۱۰۸۰×۱۳۵۰
- ۲ استوری ۱۰۸۰×۱۹۲۰
- ریلز ۱۸ ثانیه‌ای ۱۰۸۰×۱۹۲۰ با ۵ صحنه (پوستر، شیشه‌ای، نئون، پوستر بولد، اوترو استودیویی)، گویندهٔ فارسی، موزیک ساخته‌شده با کد و افکت

و همه را به همان چت تلگرام برمی‌گرداند.

## راه‌اندازی (یک‌بار)
1. Settings → Secrets → Actions → `TELEGRAM_BOT_TOKEN` = توکن ربات جدید
2. تست: Actions → render-content → Run workflow (نمونهٔ مگنی‌فورت، خروجی در Artifacts)

## تنوع
`seed` در job، پالت، ترتیب صحنه‌های میانی، رنگ و شکل QR، صدای گوینده (زن/مرد)، ریتم و آکورد موزیک و افکت‌ها را عوض می‌کند.

## قوانین محتوا که در خود قالب قفل شده
- متن گوینده فقط از فیلدهای تأییدشده ساخته می‌شود (نام، ادعای روی جعبه، ترکیبات روی جعبه).
- پاورقی ثابت: «ادعا فقط طبق نوشتهٔ روی جعبه • سؤال دارویی؟ با دکتر حصیبی مشورت کنید».

## مجوز Remotion
Remotion برای افراد و شرکت‌های تا ۳ نفر رایگان است. داروخانه در این بازه است.
